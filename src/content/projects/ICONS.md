# Project icons

Assets are served from `public/projects/`. Existing project artwork is preserved;
raster sources are resized to 160 × 160 WebP, and vector sources are copied as SVG.
The project list supplies a colored, rounded frame through `iconBackground`.
Whispr's original monochrome ghost keeps its artwork inside a violet frame.

## CycleGuider generation prompt

Use case: logo-brand. Asset type: small project app icon for CycleGuider, a cycling navigation graduation project, displayed at 48px on a personal portfolio. Create one polished colorful rounded-square app icon, straight-on and centered. Rich forest-teal rounded-square tile occupying the square canvas; a clear warm ivory bicycle silhouette with two clean circular wheels, combined naturally with a small coral-orange navigation arrow or location pointer above the front wheel. Precise simple shapes, confident balanced proportions, just enough gentle dimensional lighting for a finished app icon. Strong readable silhouette at very small sizes, generous internal breathing room, no text, no letters, no mockup, no extra objects, no outer shadows. Transparent outside the rounded-square tile; keep the whole icon visible with minimal outer margin.
